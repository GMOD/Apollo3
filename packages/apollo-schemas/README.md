# @apollo-annotation/schemas

The [Mongoose](https://mongoosejs.com/) schemas for the MongoDB collections that
the [Apollo](https://apollo.jbrowse.org) collaboration server stores:
assemblies, reference sequences and their sequence chunks, features, changes,
checks and check results, files, exports, users, and the JBrowse configuration.

This is an internal package. It's published so the other Apollo packages can
depend on it, and its API can change in any release. To use Apollo, see
[apollo.jbrowse.org](https://apollo.jbrowse.org).

This package is part of the [Apollo monorepo](https://github.com/GMOD/Apollo3).
